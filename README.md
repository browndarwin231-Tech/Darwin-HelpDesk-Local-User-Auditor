# Darwin-Local-User-Auditor

## Overview

This PowerShell project audits local Windows user accounts and administrator group membership.

It helps security analysts identify enabled accounts, administrator privileges, and recent user activity.

---

## Features

- Lists all local user accounts
- Shows account enabled/disabled status
- Displays last logon timestamps
- Lists local Administrators group members
- Beginner-friendly PowerShell security project
